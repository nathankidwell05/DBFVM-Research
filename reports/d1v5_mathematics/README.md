# Mathematics and physics of the KT-D1V5 solver

**Start here:** [`d1v5_solver_simple_guide.pdf`](d1v5_solver_simple_guide.pdf) is a
16-page plain-language version covering the same ideas and results without the
derivations. The full technical report is described below.

[`d1v5_solver_mathematics.pdf`](d1v5_solver_mathematics.pdf) explains, without
reference to code, the mathematics and physics behind the one-dimensional
KT-D1V5 finite-volume discrete Boltzmann solver: the BGK kinetic model, the
KT-D1V5 equilibrium and its moment system, a Chapman–Enskog analysis of the
discrete model, the exact Sod Riemann solution, finite-volume upwinding, MUSCL
and generalized-minmod TVD theory, SSP-RK3 stability, and the error norms. It
then reports and interprets:

- a five-grid convergence study (`Nx = 3125–50000`, `tau = 5e-6`,
  `CFL = 0.025`, `theta = 1.20`);
- the five-limiter comparison at `Nx = 6250` with the same `tau` and CFL;
- a generalized-minmod `theta` sweep from 1.0 (minmod) to 2.0 (MC).

## Build

```bash
tectonic d1v5_solver_simple_guide.tex
tectonic d1v5_solver_mathematics.tex
```

`results_section.tex` and `summary_section.tex` are included by the main file.
Table bodies in `data/` and all figures in `figures/` are generated by MATLAB.

## Regenerate the numbers and figures

From `scripts/` in MATLAB (the scripts locate the solver in either the GitHub
layout, `matlab/d1v5/`, or the OneDrive research-folder layout):

```matlab
verify_kt_d1v5_theory      % numerical checks of the analytical results
make_theory_figures        % figures that need no solver output
make_results_figures       % figures and LaTeX tables from saved runs
```

`make_results_figures` reads the cached runs written by
`matlab/d1v5/run_d1v5_gminmod_L2_convergence.m`, the output of
`matlab/d1v5/d1v5_sodshock_limiter_history_comparison.m`, and the
`run_d1v5_theta_sweep(theta)` results, all under `matlab/d1v5/results/`
(ignored by Git because the MAT files are large).
